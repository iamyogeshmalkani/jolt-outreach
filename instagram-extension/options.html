Jolt Instagram finder settings

Where results go

The same token as the TikTok finder works. Or make one at GitHub, Fine-grained tokens: pick Only select repositories and choose this repo, then under Repository permissions set Contents to Read and write. It stays in this Chrome and is only ever sent to GitHub.

Keywords to search for

Each run searches Instagram for these and keeps the recent, popular reels. One entry per line. If Instagram's search shows nothing for a keyword, its hashtag is tried (phone addiction becomes #phoneaddiction).

Claude checks the comments

With a Claude API key, Claude reads each comment on a qualifying reel and keeps the ones where the writer is talking about their own screen time, doomscrolling, brain rot, phone addiction or other digital habits that affect them. Without a key, or if Claude can't be reached, the list below is used instead. The key stays in this Chrome and is only ever sent to Anthropic.

Comments to keep

For each reel that qualifies, the top 50 comments are read. If Claude is not used, the ones that mention any of these are saved with it. One entry per line. Spacing and hyphens don't matter ("brain rot" also finds "brainrot"), and an entry can be the start of a word ("procrastinat" finds procrastinating). Comments of fewer than 5 words are skipped. Comments that look like they come from a minor, touch on self-harm, are adult, or are promotions are never saved.

What counts as a good reel

Instagram's search does not show likes, so each reel is opened to read them. The posting date is read from the reel's address, so old reels are skipped without opening.

Automatic runs

Only used when "Also run by itself every hour" is ticked in the popup.
