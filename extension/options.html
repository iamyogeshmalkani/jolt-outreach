Jolt finder settings

Where results go

Make one at GitHub, Fine-grained tokens: pick Only select repositories and choose this repo, then under Repository permissions set Contents to Read and write. It stays in this Chrome and is only ever sent to GitHub.

Topics to search for

Each run searches TikTok for these topics and keeps the recent, popular videos. One entry per line.

Claude checks the comments

With a Claude API key, Claude reads each comment and keeps the ones where the writer is talking about their own screen time, doomscrolling, brain rot, phone addiction or other digital habits that affect them. Without a key, or if Claude can't be reached, the list below is used instead. The key stays in this Chrome and is only ever sent to Anthropic.

Comments to keep

For each video that qualifies, the top 50 comments are read. If Claude is not used, the ones that mention any of these are saved with it. One entry per line. Spacing and hyphens don't matter ("brain rot" also finds "brainrot"), and an entry can be the start of a word ("procrastinat" finds procrastinating). Comments that look like they come from a minor, touch on self-harm, are adult, or are promotions are never saved.

What counts as a good video

The comment count is only known once a video is opened, so a run opens the most-viewed results of each search first.

Automatic runs

Only used when "Also run by itself every hour" is ticked in the popup.
