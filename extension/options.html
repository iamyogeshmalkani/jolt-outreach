Jolt finder settings

Where results go

Make one at GitHub, Fine-grained tokens: pick Only select repositories and choose this repo, then under Repository permissions set Contents to Read and write. It stays in this Chrome and is only ever sent to GitHub.

Topics to search for

Each run searches TikTok for these topics and keeps the recent, popular videos. One entry per line.

Competitors are searched as "name app review".

What counts as a good video

The comment count is only known once a video is opened, so a run opens the most-viewed results of each search first.

Automatic runs

Only used when "Also run by itself every hour" is ticked in the popup.
